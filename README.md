# CodeAlpha - Unemployment Analysis with Python

## Project Overview

This project is completed as part of the CodeAlpha Data Science Internship.

The objective of this project is to analyze unemployment rate data in India using Python. The analysis includes data cleaning, exploratory data analysis, visualization, COVID-19 impact analysis, and monthly unemployment patterns.

## Dataset

The dataset used in this project is:

**Unemployment in India.csv**

The dataset contains information such as:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Analysis Performed

1. Data cleaning and preprocessing
2. Missing value analysis
3. Unemployment rate analysis
4. Unemployment trend visualization
5. COVID-19 impact analysis
6. Monthly unemployment pattern analysis

## Key Findings

- Average unemployment rate before March 2020 was approximately **9.51%**.
- Average unemployment rate during March–December 2020 was approximately **17.77%**.
- April had the highest average monthly unemployment rate at approximately **23.64%**.
- July had the lowest average monthly unemployment rate at approximately **9.03%**.
- The analysis shows a substantial increase in unemployment during the COVID-19 period covered by the dataset.

## Project Files

The project demonstrates how Python can be used to clean, analyze, and visualize unemployment data and examine changes in unemployment during the COVID-19 period.
